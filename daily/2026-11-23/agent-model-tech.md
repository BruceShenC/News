**今天值得看的是 OpenAI 披露的预训练损失曲线。** 它提供了观察基座模型进展的连续指标，却不能替代 Agent 任务成功率；同时，推理引擎开始直接接管会话亲和与请求优先级。

1. **OpenAI：用困惑度跟踪预训练进展。** 官网标注 11 月 22 日，作者北京时间 23 日 01:03 发帖。文章用固定留出数据衡量下一个 token 的预测，并披露内部曲线：GPT‑3.5 对数困惑度约 0.99，GPT‑4 约 0.91。数值来自内部代码库的固定快照，不同实验室或语料不可直接横比；后训练、推理预算与工具使用收益也不会自动反映在基座困惑度上。这是研究提议，不是模型发布或已采用的行业标准。[OpenAI 原文](https://openai.com/index/perplexity-and-intelligence/) · [作者发布帖](https://x.com/merettm/status/2124549218995949967)
2. **TensorRT-LLM v1.3.0：会话与请求优先级进入引擎。** 11 月 20 日发布页显示，新版分离式推理支持会话亲和与生成优先调度，OpenAI 兼容接口可按请求传 priority，投机解码能按接受率自动停用。字段存在不等于多租户 SLA、抢占、容量隔离或跨实例优先级。Rubin 仍是预览，硬件与后端组合需看版本矩阵。[NVIDIA 发版说明](https://github.com/NVIDIA/TensorRT-LLM/releases/tag/v1.3.0)
3. **Genie 4 API：从一段视频转向可持续控制的会话。** Google 11 月 19 日宣布通过 Gemini Interactions API 和 AI Studio 向开发者开放，API 需付费层。用文本或图像初始化，随后通过按键或文本实时操控，画面和声音随交互持续生成。这不是世界模型首次发布，也不是物理仿真保证。关闭浏览器页签不代表停止服务生成，需显式结束会话才停计费，交互延迟随服务区域变化。[Google 公告](https://blog.google/innovation-and-ai/technology/developers-tools/genie-4-in-gemini-api/) · [开发者文档](https://ai.google.dev/gemini-api/docs/genie)
4. **Clover：历史上下文递推，当前文本块并行修订。** 技术报告北京时间 11 月 18 日 23:46 提交，是早前预览模型的披露，不是本周刚开放权重。35B 总参数、约 3B 激活；递推状态保存先前文本，在当前块内以双向注意力联合修订 token，可并行但仍有去噪计算。680 token/s 为开发者内部 Agent 负载、单 GB300、BF16、batch 1 数据，不等于广泛负载吞吐或端到端延迟。[报告](https://arxiv.org/abs/2611.24636) · [模型卡](https://huggingface.co/Diffuspace/Clover-35B-A3B-Preview)
5. **ARISE：将单次失败和长期规则分开。** 预印本北京时间 11 月 18 日 06:38 提交。不改模型权重、工具或工作流；先检索失败案例和修正建议，再将重复修订归纳为规则，只在留出任务准确率提高时接纳。作者在 SOP-Bench 与 τ²-bench 报告改进，尚未证明跨组织、跨工具或长周期运行有效，结论依赖留出任务的代表性。[ARISE 论文](https://arxiv.org/abs/2611.23588)

**两点判断：** 一是基座、引擎和任务分层衡量；困惑度、生成速率和 Agent 任务成功率分别回答不同问题。二是跨轮状态明确归属：引擎管理会话亲和，交互 API 管理流结束，记忆层管理经验何时升级为规则。
