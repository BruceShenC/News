# 10月15日｜大模型、Agent 与测试质量简报

日期：2026-10-15（Asia/Shanghai，北京时间 UTC+8）

归档说明：本文保留 2026-10-15 当期调研内容、来源和统计口径，不代表当前状态。仅将个性化称谓改为通用表述；未重新研究或执行项目。

今天精选6条。最值得关注的是：推理接口返回成功，仍可能发生数值错误或请求间状态串用。以下测试建议是我的工程判断，公开实验结果均注明了边界。

1. 推理正确性：Mamba2 的首版 NaN 修复仍漏掉配置
北京时间今天08:21提出的 vLLM PR #61718，补充逐配置运行真实内核的测试。作者在 H20-3e 上发现，较早修复保留的配置仍有一项在100次调用中出现81次 NaN；新方案剩余12项均为0/100。
可借鉴：自动调优不能只测速度，要覆盖所有候选配置，同时校验有限值和参考输出误差。仅检查 NaN 还不够，测试也发现过有限但严重错误的数值。
状态：PR仍待审，单卡结果，尚无完整服务端到端验证。[修复与测试证据](https://github.com/vllm-project/vllm/pull/61718)

2. 推理隔离：Cascade＋CPU KV卸载出现前缀串用报告
北京时间今天02:00提交的问题显示：vLLM 0.30.0 特定配置中，一个不共享前缀的请求混入共享前缀批次后，11/12次出现明显输出偏差，接口仍返回200；关闭Cascade的对照为0/12。
可借鉴：做“单请求基准 vs 混合批次”差分测试，覆盖KV传输在途、请求到达时序和缓存开关，结合token及logprob判断。
边界：Cascade默认关闭；报告使用同一cache_salt，不能据此声称跨租户泄漏。问题仍开放。[复现与对照](https://github.com/vllm-project/vllm/issues/61673)

3. 训练质量：UltraBERT显示 loss下降与业务收益可能脱节
研究团队10月14日发布模型介绍与150M／380M英语编码器，论文最初提交于10月10日。实验中，训练与验证loss继续下降，但分类和检索成绩约在1–2T tokens后趋于饱和；高掩码率下蒸馏还可能损伤检索。
可借鉴：checkpoint验收同时保留分类、检索、长文本任务曲线，按任务检查退化，避免只用loss选模型。用于知识库场景，可补Recall@K、nDCG及长文不同位置的召回测试。
限制：这是该编码器系列的研究结果，不能直接推广到全部生成式大模型或中文检索。[团队发布](https://huggingface.co/blog/dmis-lab/ultrabert) · [论文](https://arxiv.org/abs/2610.15028)

4. AI帮助测试：Kerno发布v1运行时QA工作流
10月14日正式发布，整合真实后端流程测试、变更影响分析、覆盖和行为变化展示，测试可入仓库并在CI中重放、输出JUnit。
价值：将验证推进到数据库、队列和跨接口流程，而不止生成用例文本。建议用已知缺陷集评估检出率、误报率、重复运行稳定性及人工维护时间。
注意：部分流程及MCP测试能力9月已上线；厂商效率宣传缺少足够方法说明，不作为确定收益。[v1公告](https://www.kerno.io/blog/kerno-v1/) · [历史变更记录](https://kerno.gitbook.io/docs/getting-started/changelog)

5. 测试AI系统：IMDA发布Agent测试入门指南
10月14日发布，覆盖风险识别、现实测试场景、执行日志分析和持续重测，明确关注工具调用准确率、代理交接准确率和人工介入率。
可借鉴：把完整执行轨迹纳入验收，逐步检查参数、权限、状态变化和交接结果；人工介入率需结合任务风险解释，不能一味追求低。
状态：已发布的实践指南，属于测试方法参考。[官方发布](https://www.imda.gov.sg/resources/press-releases-factsheets-and-speeches/new-initiatives-to-strengthen-ai-safety-and-resilience)

6. Agent安全评测：单轮拒绝正常，多步骤组合仍可能失守
Anthropic 10月14日披露外部压力测试：直接违规请求能被拒绝，但拆成多个表面正常的小任务后，系统可能漏掉整体意图；公司称已增加相关检测分类器。
可借鉴：用成对用例比较“完整任务”和“拆分多轮任务”，统计整条轨迹的违规完成率、正常任务误拦率及检测延迟。内部高分不能替代跨语言、多轮和真实流程评测。公告中的官方投票信息接入属于后续计划，尚不能算全部上线。[评测发现及措施](https://www.anthropic.com/news/2026-us-midterms)

优先小范围验证两项：
- 推理平台：增加“混合批次＋缓存／卸载开关”的输出差分探针，能发现HTTP成功率看不到的错误。
- 测试Agent：选一个隔离测试服务，评估“生成→执行证据→固定回归”的闭环；重点看真实缺陷检出和维护成本。
