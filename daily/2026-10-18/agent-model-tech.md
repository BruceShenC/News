# 10月18日 · Agent 与大模型技术热点

1. DeepSeek V4.1-Flash-1017：模型与搜索工具一起更新
10月17日正式发布，网页、App、API 已更新，调用名与价格不变，MIT 权重公开。官方报告 Terminal-Bench 4.0 从31.2升至42.3、DeepSWE v1.1从74.2升至77.0，并称输出更短、任务耗时下降；同期开放独立 Search／Fetch 接口，分别返回结构化搜索结果和网页 Markdown。
价值：可用现有 Agent 任务重测成功率、总成本与耗时。限制：成绩来自官方，运行框架、重试策略会影响结果；这是小版本更新，没有证据表明换了全新架构。HF 模型页约952次点赞，并已有 HN、Reddit 讨论。
[官方更新](https://api-docs.deepseek.com/updates/)｜[模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017)｜[搜索接口](https://api-docs.deepseek.com/guides/search/)

2. OpenGCUA：让模型决定何时看屏幕、何时调用代码／API
10月15日论文，16日进入 HF 日榜；研究首版已公开，真机工具与跨设备 SDK 仍为预览。方法将部分观察、状态和执行决策从固定框架移交模型，把 GUI、辅助功能树、API、Shell 组合进可执行程序。
作者在 OSWorld-v2 测试8个模型，平均部分得分提高19.6分、操作步数减少53%。价值在于优化整个电脑 Agent 执行架构；但部分得分不等于完整任务成功率，少步数也不直接等于低成本，真机实验仍较小。社区约315票。
[论文](https://arxiv.org/abs/2610.22200)｜[首版说明与讨论](https://huggingface.co/papers/2610.22200)

3. Mosaic：把上下文压缩、子 Agent 分支纳入 RL
10月15日研究预印本。真实 Agent 会跨多个 session 执行，但训练经常按单 session 处理；Mosaic 同时估计整条任务与各 session 的贡献，改进最终奖励向不同分支的分配。
在 Qwen3.5-4B 的 BrowseComp 实验中，压缩与子 Agent 两种模式均优于奖励广播基线，平均使用更少 session。价值：上下文管理和多 Agent 协作变成可训练能力。限制：证据主要来自一个小模型和网页研究任务，不能外推到通用长期自主工作。社区约53票。
[论文](https://arxiv.org/abs/2610.22174)｜[作者说明](https://huggingface.co/papers/2610.22174)

4. Waypoint-OPD：用教师中间检查点筛选蒸馏信号
10月15日研究预印本。在教师 RL 前后两个检查点之外，再加入一个中间检查点；早期、后期策略变化方向相反时，降低对应信号的蒸馏权重。
作者在3种学生规模、数学与代码共6组设置中获得所比较方法的最高领域平均分。价值：更细地筛选教师训练过程中稳定学到的能力。限制：需要中间检查点及额外教师评分，闭源 API 用户通常无法直接采用；实验主要基于 Qwen3 家族。查询时 HF 当日论文榜第1、约665票。
[论文](https://arxiv.org/abs/2610.21601)｜[社区关注](https://huggingface.co/papers/2610.21601)

5. Intern Lumina U2：多码本视觉表示＋离散扩散
10月14日研究预印本，16日进入 HF 日榜。每个视觉位置使用多个码本，在不拉长位置序列的情况下增加表示容量；扩散骨干并行处理位置，轻量自回归头预测位置内部编码。
统一图像、视频、3D理解及图像生成、编辑。作者报告稳定性感知采样让图像生成加速4.45倍，属于特定基线和设置，不能当成普遍性能收益。价值是探索表示质量、序列长度和并行推理的折中。社区约42票，仍属较小范围研究关注。
[论文](https://arxiv.org/abs/2610.20818)｜[技术说明](https://huggingface.co/papers/2610.20818)

6. Self-Evolving Agent Harness：把持续修改纳入审批与验证
10月13日框架和理论研究，16日进入 HF 日榜。讨论权重不变时，提示词、记忆、工作流、代码和插件配置如何依据反馈持续演进，明确区分“提出修改”和“允许上线”。
价值：为 Agent 自我改进建立可审查边界，强调新验证数据、历史回归预算和独立权限控制。限制：理论保证依赖明确假设，不能宣称已实现可靠、无限递归自我提升。社区约198票。
[论文](https://arxiv.org/abs/2610.18813)｜[讨论](https://huggingface.co/papers/2610.18813)

值得继续跟的两个方向
- 模型与执行框架共同优化：评价真实任务成功率、耗时、token 和工具成本，避免只比模型分数。
- 训练覆盖真实 Agent 执行结构：压缩、子 Agent 分支、工具选择正逐步进入训练目标；对 Agent 平台，更值得关注这些能力能否稳定迁移到自己的任务。
