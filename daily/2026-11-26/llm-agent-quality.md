# 大模型与 Agent 质量、测试与工程资讯｜2026-11-26

**观察窗口：北京时间 11 月 25 日 09:30 至 26 日 09:00。** 今天最值得看的是 Anthropic 的迁移复盘：测试集通过率看起来很高，生产流量却暴露出另一批兼容问题。

## 大模型平台与推理质量

1. **Anthropic Messages API 迁移：约 98% 测试通过，不等于线上输入等价。** 11 月 25 日公布的工程复盘：4 月 Rust 版通过约 98% 的测试，但早期线上影子对照中，仅约四分之一的输入路径结果与 Python 版匹配。两者分母不同，也不是“四分之一的回答正确”。他们让模型只生成一次，把同一输出交给两个版本，比请求预处理和流式输出的各阶段，排除模型采样差异，也避免双跑模型计费。报告披露的差异包括工具描述遗漏、换行被吞、终止用量字段缺失。**可迁移验证（未跑）：** 用合成流固定工具调用，逐项断言事件顺序、重组后的参数与终止用量；再故意只删用量事件，确保响应仍是 200 时也会失败。[官方复盘](https://www.anthropic.com/research/migrating-api-to-rust)
2. **vLLM #68841：Rust 前端不支持的开关改为启动即报错。** 11 月 25 日合入。改动前，有的开关能随服务启动，但请求端才收到 501；Responses 状态存储开关还可能被忽略。两种入口有明确差异：Python 管理的 `vllm serve` 会省略关闭值，而直接运行 `vllm-rs serve` 时，显式的 `VLLM_ENABLE_COHERE_API=0` 也会被当作设置了不支持的开关。作者报告 17 项针对性 Python 测试通过，并给出 Rust 测试入口；此前 GB200 探测早于最后的环境变量改造。**建议：** 两种入口分别验未设置、显式关闭、启用，单看 readiness 不够，启动通过的组合还要验证承诺的接口。[PR 与测试入口](https://github.com/vllm-project/vllm/pull/68841)
3. **SGLang #50299：DFLASH／DSpark 不再默默改写投机步数。** 11 月 25 日合入。此前显式填非 1 会警告并改成 1。作者在 macOS ARM64 对两个算法跑 CLI 解析与配置入口：不填或填 1 应解析为 1；填 2、0、−1 应报出指明参数的错误。现有 server args 单测通过，未新增专用回归，未跑 GPU 推理。这里检查的是调度器的 `--speculative-num-steps`，不是算法的验证窗口。[PR 与验证记录](https://github.com/sgl-project/sglang/pull/50299)
4. **lm-evaluation-harness #4658：用固定分数测 SGLang 评测适配器。** 11 月 25 日跟进，PR 仍开放、未合入。测试只替换本地 SGLang 引擎，给定可手算的 token 分数，验证左截断后只计 continuation、批次顺序还原、greedy 判定、滑窗文档总分与缓存写入。作者报告新增滚动测试后 95 项离线测试通过；这验证的是适配层计算与记账，不是真实模型的数值一致性或 GPU 行为。[PR 与作者运行记录](https://github.com/EleutherAI/lm-evaluation-harness/pull/4658)

## AI 辅助测试与证据

5. **Playwright #44392：存在 trace 附件，不代表录到了目标窗口。** 11 月 25 日草稿，未合入。原问题在 1.65.1 报告：Electron 测试有 runner 步骤，但没有窗口 DOM 快照或视频。Playwright 的机器人在 Linux、Electron 42.11.16 上复现，报告 41 项定向测试通过，并验证缺钩子时回归失败、修复后通过；首次重试才保留录像，提前关闭的窗口也在测试覆盖内。Windows 与 macOS 未测。**可迁移检查（未跑）：** 打开产物并核对窗口、失败动作、尝试序号；加入缺失产物的反例，不以“附件存在”判通过。[原问题与测试记录](https://github.com/microsoft/playwright/issues/44384) · [草稿 PR](https://github.com/microsoft/playwright/pull/44392)
