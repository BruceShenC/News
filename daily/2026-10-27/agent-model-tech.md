# Agent 与大模型技术热点｜2026年10月27日

日期：2026-10-27（Asia/Shanghai，北京时间 UTC+8）

归档说明：本文保留 2026-10-27 当期调研内容、来源和统计口径，不代表当前状态。仅将个性化称谓改为通用表述；未重新研究或执行项目。

本期两项过去24小时的重要发布＋四项近7日研究。论文首发与社区传播日期分开标注；性能结果均为作者报告，未独立复现。

1. GPT‑6.1 Terra：视觉操作能力向低成本档位下沉
10月26日正式发布，主攻视觉推理、电脑操作与写作，已提供API及ChatGPT Work、Codex中的相应套餐访问。
标准API每百万输入／缓存输入／输出token价格为1／0.05／5美元，较GPT‑5.6 Terra、GPT‑6.1 Sol标价低50%。官方在Agents’ Last Exam报告中等推理档较上一代提高15个百分点、任务成本约三分之一。
价值：批量票据处理、应用操作等任务多了成本选择；但任意业务未必复现相同收益，复杂编码仍需更强模型，不应把每token降价直接当端到端成本降幅。
热度依据：本次检索的Reddit发布讨论已有数百票，只代表关注，不是独立性能证明。
来源：[官方发布](https://openai.com/index/introducing-gpt-6-1-terra/)；[API更新记录](https://developers.openai.com/api/docs/changelog)；[社区讨论](https://www.reddit.com/r/codex/comments/1xg4eqq/introducing_gpt61_terra/)。

2. Oracle：把企业配置知识变成Agent可操作的Skills
10月26日平台公告，已有早期客户。AI Success Navigator以FSCR机器可读配置登记表为基础，将配置规则、最佳实践封装为Skills，交给发现、设计、配置、测试、集成等专门Agent。
价值：不只是检索文档，而是围绕权威配置定义执行，减少生成结果与产品约束脱节；值得知识网关设计参考。
限制：绑定Fusion产品体系，公告没有给出所有新增Agent统一全面可用日期；客户效率宣传不是受控实验。
来源：[Oracle公告](https://www.oracle.com/news/announcement/ai-world-oracle-unveils-agentic-ai-platform-to-accelerate-implementation-of-oracle-fusion-cloud-applications-2026-10-26/)。

3. RSIHub：把Agent自我改进拆成可比较的流程
10月23日论文，26日进入HF社区讨论。用recipe组合选择、执行、分析、修改等算子，明确提示、Skills、工具和编排代码的可修改范围，将评估器及框架核心留在边界之外，记录候选版本来源。
价值：让不同演化策略共用实验基础设施。作者实现多种策略，最大整体pass@1提升13.5个百分点。
限制：策略排名随场景变化，收益未必迁移到留出任务；不是“可以无限自我升级”的证据。
来源：[论文](https://arxiv.org/abs/2610.32253)；[项目](https://github.com/simple-agent-lab/RSIHub)。

4. OPST：模型自造课程，再做在线自蒸馏
10月23日论文，26日社区传播。从粗粒度主题生成问题、答案及推理示范；要求模型在新上下文和改写问题中重现答案，经过自洽筛选，再用带额外推理信息的教师分布训练学生。
价值：减少人工题库、标准答案及更强外部教师的需求；研究也扩展到无标签图像上的视觉问答。
限制：“Data-Free”不是完全没有数据或人类输入，主题仍需选择，视觉版仍用图像；稳定重复的错误也可能通过自洽检查。适合研究低标注成本后训练，不代表凭空获得新知识。
来源：[方法与实验](https://arxiv.org/html/2610.32770v1)。

5. HiSTEVE：规划器要知道行动模型能做什么
10月22日论文，26日社区传播。结合结构化进度记忆、受能力约束的VLM规划器与VLA控制器，用画面和动作上下文判断子任务完成，而非仅凭规划器自我宣告。
作者在Minecraft的MineStudio Bench报告85.0%，OpenHA平均成功率37.4%。
价值：可借鉴“规划→执行→完成证据→恢复”的分层关系。
限制：仍是游戏任务，原子能力接口人工定义，增加能力需要训练；不能直接当作桌面GUI Agent效果，也不是部署中持续更新参数。
来源：[论文](https://arxiv.org/abs/2610.31162)；[架构与限制](https://arxiv.org/html/2610.31162v1)。

6. TWIG：统一表示量化、稀疏化和权重共享
10月22日论文，26日社区传播。将权重编码成符号、二次幂移位、置零门及共享码表索引的决策路径，让相似权重共享部分结构。
价值：为固定权重芯片提供压缩与电路联合设计方向。
限制：目前仅在一个大模型的5个权重矩阵上验证；相同层误差下，作者报告较GPTQ减少约9%–15%加法操作，强异常值矩阵约20%–55%。这不是整模型精度、GPU吞吐或实测能耗收益。
来源：[论文](https://arxiv.org/abs/2610.31931)。

值得关注
- 受约束的自主性：权威配置、明确修改边界、能力感知规划，比单纯增加Agent数量更接近可靠部署。优先读RSIHub的边界设计。
- 分清“降成本”的层级：Terra是服务价格与任务成本，OPST是监督需求，TWIG是电路操作，不能混成同一种加速。OPST尤其值得检验“自洽但错误”的过滤盲区。
