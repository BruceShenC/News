# 10月19日 · Agent 与大模型技术热点

日期：2026-10-19（Asia/Shanghai，北京时间 UTC+8）

归档说明：本文保留 2026-10-19 当期调研内容、来源和统计口径，不代表当前状态。仅将个性化称谓改为通用表述；未重新研究或执行项目。

本轮未核到过去24小时内值得替换昨日头条的新主流模型发布。今天精选近7天尚未覆盖的5项，重点是记忆组织、长程任务训练和小显存部署。

1. Librarian Agents：把“整理上下文”训练成能力
状态：研究预印本，附代码；10月15日17:35 UTC提交，北京时间10月16日01:35。
机制：builder agent在问题到来前，把文档整理成分层文件、摘要与原文引用；回答agent使用这些材料，其回答准确率再用于训练整理策略。作者报告 BrowseComp-Plus 较最强检索／预计算基线提升33个百分点。
价值：对知识网关 有参考意义，可在统一检索接口之外，研究可复用的跨文档证据组织。
限制：目前只测静态文档问答，增量更新仍是开放问题；原始查询 token 并未更少，不能把“按正确答案归一化的成本改善”理解为普遍省 token。[论文与限制](https://arxiv.org/html/2610.22273v1)

2. MLExpert：用中间实验结果训练长程规划
状态：研究预印本，附代码和模型；10月15日17:56 UTC提交，北京时间10月16日01:56。
机制：35B MoE先做分层 SFT，再用 Windowed Interaction RL，将两次实验结果之间的多轮决策作为奖励窗口；异步采集与策略校正允许整条实验轨迹结束前更新模型。
价值：把工具调用、实验选择和结果分析一起训练，缓解长任务只有最终奖励的问题。
限制：22项 MLE-Bench Lite 任务的平均获牌率37.9%→72.7%是作者实验；每项允许12小时、最多3,000步和一张H200，不能外推为通用自主科研已经成熟。[论文及实验条件](https://arxiv.org/html/2610.22344v1)

3. DeltaStreamer：视频记忆保存变化，需要时回看证据
状态：研究预印本，公开代码与交互演示；10月14日09:19 UTC提交，北京时间当日17:19，10月16日进入HF论文页。
机制：持续记录相邻帧的变化和证据位置；提问后，planner决定检索哪些记忆、回看哪些历史帧，以补回摘要遗漏的视觉细节。
价值：适合长视频、直播等“先观察、后提问”的场景，也提示多模态 Agent 不应只依赖一次性摘要。
限制：回看依赖历史帧仍可访问，增加存储和响应开销。OVO-Bench 66.07%、StreamingBench 59.53%均为作者评测。[论文](https://arxiv.org/abs/2610.19849)

4. Nemotron 3.5 Bolt：围绕24GB预算联合优化模型和推理
状态：模型、量化权重与推测解码 drafter 已发布；官方发布日期10月15日。
机制：从120B-A12B Super VL结构压缩为74B-A9B混合 Mamba-Transformer；主要专家权重量化至约2.06bit，用量化感知蒸馏恢复能力，再配合 LiLiCorr 并行推测解码。
价值：端侧 Agent 的优化目标进一步转向显存、速度与任务能力的组合。
限制：约84 token/s来自指定 RTX Spark 和软件配置，不能外推为任意24GB设备的速度；它也不是官方同内存比较组中最快的模型。[官方技术说明](https://research.nvidia.com/labs/nemotron/Nemotron-3.5-Bolt-24GB/)

5. Claude复原ECDSA参数来源：可复算的研究型 Agent 案例
状态：10月16日官方研究文章，附复算代码；使用内部研究模型，并非新模型公开发布。实验发生在10月，具体日期未披露。
机制：提出旧式伪随机数生成器假设，编写扫描器，结合状态恢复与格基约化，复现多条标准曲线种子的生成过程。
价值：展示“提出假设→调用计算工具→逐项验证”的科研流程，结果可由独立程序复算。
限制：研究的是参数来源，并未破解ECDSA；部分基点、一个种子，以及跳过某些候选曲线的原因仍未解释。[研究与复算代码](https://www.anthropic.com/research/ecdsa-curve-origins)

值得深入的两个方向
- 任务导向的记忆组织：优先看 Librarian Agents，比较动态更新、原文追溯和包含预处理的总成本，判断能否补强目标知识库语义层。
- 长程任务的中间奖励：参考 MLExpert，将实验选择与结果分析作为训练单元；重点比较相同预算下的任务完成率与端到端耗时。
