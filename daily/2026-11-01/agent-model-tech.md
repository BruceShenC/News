**2．链式检索从自身错误中训练，而不只学习理想证据链**
论文日期：10月29日提交，30日公告。**预印本研究。**
On-policy State Training让当前embedding模型每个epoch先跑出自己的检索链，再用这些真实访问状态与理想历史混合训练。遇到已检错的段落，目标仍是最早缺失的正确证据，其他正确后续证据被mask，避免误当负例。
作者在Qwen3-Embedding-0.6B上报告：MuSiQue五次种子平均的前5段完整证据覆盖率C@5为49.3%；同配方单种子消融中，teacher forcing为44.6%，on-policy为50.5%。**不能将两个不同实验汇总口径直接相减。**检索链本身无需逐步调用大语言模型，适合探索低成本多跳RAG。
限制：需要gold证据监督和周期性重采样；论文构造的长链测试不是任意企业语料。四跳问题在5段预算下，两种训练的完整覆盖仍低于10%，不能把平均提升当复杂链路已解决。
[论文与消融](https://arxiv.org/html/2610.40409v1) · [公开代码](https://github.com/yausankit/on-policy-state-training)

**3．记忆检索可否像“沿路走”，而非每一步重新全局搜索？**
论文日期：10月29日提交，30日公告；元数据注明获NeurIPS 2026长上下文Workshop接收。**早期概念验证，不是成熟记忆产品。**
Retrieval as Traversal把记忆内容与地址分离，让检索头保留位置、局部移动。目标不是简单把相似文本放一起，而是让互补证据容易共同取到，冗余内容不要挤占同一个局部预算。
MiniGrid Memory中，5-token上下文的持续移动检索头在约0.59M训练步达到平均回报0.95，Gaussian绝对寻址约0.94M。潜在价值是复用相邻任务步骤的检索状态。
**核心限制更重要：实验地址由环境坐标手工给定，未学习论文提出的价值索引，也只需取回一项信息。**短上下文基线还能通过等待/转身把线索编码进自身行为，所以结果支持学习效率差异，不能宣称新增记忆能力或已经验证长文档连续检索。
[论文、负控与限制](https://arxiv.org/html/2610.40545v1)

**4．Prefill预测输出长度存在噪声下限，调度不宜只押一个点估计**
论文日期：10月29日提交，30日公告。**理论分析＋实证研究。**
把decode长度视为随机停止过程：即使prompt不变，采样路径也会改变结束时刻。论文在分段更新等假设下建立近似正态模型，推出最佳prefill点预测的MAE下限约为每prompt长度标准差的0.798倍；复杂预测器无法提前知道尚未发生的采样噪声。
主要实证使用Qwen3-32B非思考模式、ShareGPT 300个测试prompt，每个重复200次。多种预测器趋近相似误差，提示容量/排队规划应考虑分布和风险余量，或在decode期间分阶段更新，而非只继续加大预测器。
限制：不是适用于一切模型/greedy/短输出的无条件定理。数据由PD分离流水生成，batch和低层数值行为未严格控制；论文承认运行期计算不一致可能贡献额外变化。在线更新还增加算力与时延，不能直接视为免费优化。
[论文、假设与数据限制](https://arxiv.org/html/2610.40541v1) · [代码与分析工具](https://github.com/ShwStone/DecodingPredict)

**5．Algebraic World Model：先学环境规则，再证明目标可达或不可达**
论文日期：10月29日提交，30日公告。**预印本研究，非基础模型发布。**
AWM先通过交互构造可执行Python假设，再整理成类型化对象和共享规则，最后转为Lean4模型，产生可由内核检查的证明。它把环境建模错误与逻辑推导错误显式分开，适合研究可解释规划与带约束的决策。
作者在25个公开ARC-AGI-3游戏中，对183关获胜轨迹完成Lean重放；两个封闭关卡的六次运行均产出模型内证明，但最初只有4/6边界正确，收到存在更便宜解的反馈后修正规则才到6/6。
关键限制：**证明正确不意味着学到的世界规则正确。**Lean只保证显式前提下的推理；环境映射仍须交互验证。当前主要是离散动作、即时可见反馈，隐藏状态、随机动力学和延迟反馈尚待测试，也不能把公开游戏结果视作未见环境通用智能排名。
[论文与模型边界](https://arxiv.org/html/2610.40503v1) · [模型、证明及重放材料](https://ephemeral6.github.io/awm-site/)

**6．多Agent实验研究：关键不是互相赞同，而是有权否决“成功”**
论文日期：10月29日提交，30日公告。**固态量子自旋实验的预印本案例。**
系统分设研究负责人、提案者、计算研究员、实验执行者、管理者和安全审查角色，通过文档交接，并让部分评审使用新上下文。在金刚石NV自旋校准研究中，Agent先排除不能区分竞争解释的实验设计，再预先固定预测与验收规则。
首轮目标结果虽符合预测，独立参考控制却因信号漂移失败，负责人判为“无法定论”，修改测量程序而不放宽标准；后续实验满足预设条件。价值是让协作架构包含否决、独立检查和证据不足状态，而非只追求任务完成率。
限制：人类搭建仪器、提供能力说明并设置安全边界，不能称全无人实验室。部分评审仅看到文稿/报告，未直接查看原始数据；单一平台案例不足以证明多Agent在所有科研工作流中更可靠。
[论文、角色分工与人类贡献](https://arxiv.org/html/2610.40589v1)

**值得关注的两个方向**

• **有状态检索与可修正记忆。** 链式检索训练覆盖自身失误，持续检索头复用前一步位置；可先在小型已标注多跳任务上比较完整证据覆盖和纠错能力，不宜只看单跳召回率。
• **把不确定性与前提作为一等对象。** 长度预测保留随机性，AWM显式列出规则，实验Agent允许结论暂缓。它们共同提示：系统不只要给答案，还应说明依赖哪些假设、什么证据能推翻它。

以上研究数字均为作者报告，本期未调用模型、执行实验或安装项目；研究新颖性、热度和生产成熟度是不同判断。
