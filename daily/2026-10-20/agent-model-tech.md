# 10月20日 · Agent 与大模型技术热点

日期：2026-10-20（Asia/Shanghai，北京时间 UTC+8）

归档说明：本文保留 2026-10-20 当期调研内容、来源和统计口径，不代表当前状态。仅将个性化称谓改为通用表述；未重新研究或执行项目。

今天优先看 MiniMax M3.1 Flash 正式发布，以及 CarryOn、DLite 对长程Agent上下文成本的两种改进。后四项是近7天研究，10月19日进入社区论文讨论，不把讨论日期当首发日期。

1. MiniMax M3.1 Flash：竞争重点落到每任务成本
10月19日正式上线API、M Plan和MiniMax Code；权重仍待发布。官方将近3倍在线推理提速归因于更激进的稀疏化，并称Agent使用成本降低70%。价格为每百万token输入$0.15、输出$0.60、缓存输入$0.015。
价值：值得用高频工具调用、长流程任务比较实际账单和成功率。
限制：提速及成本降幅是厂商口径，不能替代同负载测试；预览版428B/23B参数也不应直接视为最终版已确认架构。独立Artificial Analysis给出Intelligence Index 42，未证明全部Agent基准得到独立复现。
热度：LocalLLaMA主讨论约532票，评价分化。[官方发布](https://www.minimax.io/blog/minimax-m31f) · [独立评估](https://artificialanalysis.ai/models/minimax-m3-1-flash) · [社区讨论](https://www.reddit.com/r/LocalLLaMA/comments/1x9uzv9/minimax_m31_flash_released_model_weights_oct_23/)

2. CarryOn：把上下文组织成可继续使用的任务成果
论文10月13日首发、14日更新；19日进入HF讨论，约100票。它将文件、已核实发现、应用状态等组织为任务对象，附带使用条件及执行上下文；历史压缩后，仅重新核验受影响的对象。
价值：减少办公、研究Agent反复回顾已完成操作，也适合思考知识网关如何保存带有效条件的证据。
作者结果：同一Claude Opus4.7主模型下，OSWorld2.0二元成功率提高3.7个百分点，部分得分提高5.8点，总token减少51.9%；BrowseComp-Plus的100题子集准确率49%→56%。
限制：5.8点不能写成成功率提升，证据集中于一个主模型和两种环境。[论文及实验口径](https://arxiv.org/html/2610.18784v2) · [日期与社区页](https://huggingface.co/papers/2610.18784)

3. DLite：让draft模型不再维护完整历史KV
论文10月16日提交，已有推理代码和draft权重；19日HF讨论约20票。draft模型直接利用目标模型的上下文化隐藏状态做局部预测，轻量顺序头补回候选块内部的因果依赖。
价值：降低长上下文下draft缓存维护和重复历史建模成本。
作者在H800、Qwen3-4B/8B、候选块K=7配置下报告Agent类负载解码加速2.07–2.74倍。
限制：这是解码加速，不能等同整个任务完成加速；BFCL-v3不含工具执行时间，SGLang/vLLM集成及更大模型仍在路线图。[论文](https://arxiv.org/abs/2610.23787) · [代码与实验条件](https://github.com/SJTU-DAI-Sys/DLite)

4. LEV：循环使用网络层，按问题难度分配计算
10月14日论文，代码、三个checkpoint及部分数据公开；19日HF讨论约80票。相同网络层循环执行，共享读出头给候选项打分，停止器估计是否已与最深层答案一致。
价值：面向选项决策、路由、分类，探索一份权重支持不同计算深度。
作者2.6B模型在JevBench的231个公开样例上，从一轮63.2%提高到四轮76.2%；开发集离线分析显示可节省15%–24%循环计算，损失0.3–0.8个准确率点。
限制：不是线上服务提速；2.6B自适应深度在锁定测试集上没有显著超过固定深度前沿，同FLOPs也未证明全面优于稠密模型。[论文](https://arxiv.org/abs/2610.20951) · [项目与限制](https://openlair.github.io/lev/)

5. TreeOPSD：把终局奖励分配给长程Agent的中间步骤
10月16日预印本，19日HF约32票；尚未核实公开代码。从共享前缀分叉多条轨迹，将终局奖励回传为轮次级信用，再构造相对冻结行为策略、有边界的教师分布。
价值：同时应对稀疏奖励和复用同批rollout时的策略陈旧，不依赖额外critic、逐步人工标注或更强外部教师。
作者在匹配rollout预算下，报告Qwen3-30B-A3B-Thinking-2507的Deep Research设置平均提高4.97个百分点。
限制：依赖可验证终局奖励和分叉采样，尚不能外推为任意生产任务都能更低成本训练。[论文](https://arxiv.org/abs/2610.23181) · [作者说明与讨论](https://huggingface.co/papers/2610.23181)

值得深入的两个方向
- 长程Agent的历史处理成本：CarryOn优化运行时证据组织，DLite优化推理时的历史处理。分别衡量任务成功率、全部token费用和真实完成时延，不能直接把两者收益相乘。
- 同质量条件下的自适应计算：比较循环深度、稀疏化和固定模型，匹配任务、推理强度与负载，观察每个成功任务的成本。
